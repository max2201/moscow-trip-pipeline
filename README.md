# Москва, 14–22 октября — сбор данных

Данные для сайта https://max2201.github.io/moscow-trip-vue/. В таблицу экспортируются только положительные полные цены до **40 000 ₽ за 14–22 октября 2026, 8 ночей, двое взрослых**. Лимит проверяется по общей сумме, включая варианты из плана. Ограничение в 12 км при сборке снято; расстояние площадки до её центра подписано отдельно от расчёта по координатам до Красной площади. Объекты без координат не попадают на карту.

- `python run.py prices` — выдача Островка на даты поездки;
- `python run.py sources` — попытки обновить дополнительные площадки;
- `python run.py sources --source ozon yandex --max-pages 20` — ограниченный сбор выбранных площадок;
- `python run.py reviews` — отзывы новых отелей (анализ сохраняется в `cache/hotels/msk.jsonl`, сами тексты — нет);
- `python run.py build` — сборка `site-data/` для сайта;
- `python run.py all` — prices + sources + reviews + build. Каждое утро это делает GitHub Actions (`.github/workflows/update.yml`).

Установка: `pip install -r requirements.txt`, затем `python -m playwright install --with-deps chromium`. Chromium нужен только дополнительным браузерным сборщикам; сборка из кеша не требует браузера.

| Источник | Реализация |
| --- | --- |
| Островок | Существующий сбор выдачи и текстов отзывов |
| 101Hotels | Chromium и кнопка следующей страницы; цена в `.room-price` за весь срок, без завтрака и зачёркнутого тарифа |
| Ozon, Яндекс, Суточно.ру, Твил, Туту, OneTwoTrip | Обычный Chromium, чтение карточек с датами и полными ценами |
| Авито, Циан, Квартирка, Броневик, МТС Travel | Реестр и импорт; автоматический сбор пока не подключён |

В начальных данных дополнительные площадки содержат частичные снимки, проверенные через браузер. Они помечены как ручные. Наличие адаптера не гарантирует успешное обновление на GitHub Actions: сайт может потребовать проверку доступа или изменить разметку. Все источники имеют отдельный статус, время попытки, время снятия цены и флаг полного охвата. Ошибка, пустая выдача, неверные даты или сокращение выдачи более чем вдвое сохраняют предыдущий снимок. Авито в этой среде ограничено политикой доступа браузера, Циан закрывал соединение, Квартирка не ответила, Броневик вернул 503, домен МТС Travel не разрешился.

Сборщики не обходят CAPTCHA и не сохраняют cookies, токены или данные авторизации. При необходимости предложения, которые пользователь открыл самостоятельно, можно добавить:

```sh
python run.py import --source ozon --input content/import-example.json
python run.py build
```

Пример содержит реальное предложение первоначального снимка; **перед импортом заново проверьте цену**. Формат: `source`, `stop`, `items`; у объекта обязательны `externalId`, `name`, HTTPS-ссылка своей площадки, `ci`, `co`, `adults: 2`, полная `total` в RUB. `scoreMax` — 5, 10 или 100; неизвестная отмена — `free: null`. Импорт по умолчанию добавляет/обновляет объекты по ID, сохраняя остальные. `replace: true` заменяет снимок с защитой от резкого сокращения.

ID новых площадок — отрицательные 48-битные числа с пространством имён площадки. ID и отметки Островка сохранены. Одинаковое жильё на разных площадках остаётся отдельными предложениями: адреса/названия недостаточны для надёжного объединения. Гостевые рейтинги приведены к шкале 10. Каждый объект получает компоненты `cp` и метаданные `rating`: `texts` — разобранные тексты, `platform` — предварительная основа по рейтингу площадки, `none` — условная основа 6/10 без доказательств качества. Рейтинг с небольшим числом отзывов подтягивается к медиане; отсутствие разбора текстов даёт поправку вниз. Насекомые, запах, сырость, негатив и риски денег, заселения, белья и горячей воды учитываются только по прочитанным текстам. Цена и расстояние добавляются на сайте; предварительный балл без текстов ограничен 9,5.

`python run.py reviews` читает Островок, 101Hotels и Суточно.ру; можно выбрать `--source 101hotels sutochno`. У двух последних собирается доступная в HTML выборка; весь архив не считается прочитанным, у Суточно.ру тексты могут быть сокращены. Ответы владельцев и автоматические подписи к оценкам исключены. `reviewCoverage` сохраняет источник, ссылку, время и признак неполной выборки. Опубликованное число отзывов не подменяет число разобранных текстов. При сбое или уменьшении разобранной выборки предыдущий анализ сохраняется.

Проверки: `python -m unittest discover -s tests`, `python run.py build`. В CI `RUN_DOM_TESTS=1` также проверяет парсеры на автономных HTML-фикстурах, без запросов к площадкам.

Содержимое (районы, места, события) — в `content/`. Это копия сборщика поездки в Таиланд (thailand-trip-pipeline), переделанная под Островок.

Планировка выбранного предложения экспортируется в `prices` → метаданные → `housing`: `bathtub`, `rooms`, `duplex` и `evidence` с исходным названием. `null` означает отсутствие подтверждения; `rooms: 0` — студия. Количество мест, спален и `rooms_n` (номерной фонд отеля) не используется как число жилых комнат. Признаки берутся из названия выбранного номера либо отдельной квартиры, не из удобств всего отеля или отзывов о других номерах. «Ванная комната» не подтверждает ванну, двухъярусная кровать не подтверждает два уровня. Счётчики серьёзных сигналов из разобранных отзывов экспортируются в `reviewRisks`; отбор по рейтингу площадки помечается как предварительный и доступен отдельно от проверки текстов. Объекты без отзывов не проходят этот отбор.

Охват сохраняется в `coverage`: страницы, количество цен и причина остановки. `complete: true` ставится только после явного конца выдачи; стабильная прокрутка без общего размера списка остаётся неполной. Защитный предел по умолчанию — 1000 страниц. Подтверждённые цены ожидаются до 90 секунд. Счётчики площадок на сайте показывают предложения в бюджете, а не число сервисов или объединённых объектов.
